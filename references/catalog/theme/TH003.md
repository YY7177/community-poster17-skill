## 文字总结

### 社区活动海报｜设计经验总结

- **整体气质**：优先“简约、大气、亲切”，避免传统宣传海报的信息堆砌感；画面必须有明显留白和呼吸感。  
- **信息层级**：主标题最大且醒目，可使用略活泼、有亲和力的字体，避免过度方正；副标题、时间地点、正文逐级缩小，字号保持统一规范。  
- **内容精简**：删除重复解释性文案，只保留活动名称、时间、地点、品类、参与方式、必要提醒等核心信息。  
- **插图控制**：只保留一个完整的主场景，不使用大量小图标、小插画；人物数量减少，尤其避免背景出现密集人头、衣服等碎片元素。  
- **版式处理**：信息之间主动拉开距离，减少卡片和色块；正文下方不加无意义的浅色底框，用留白、字号和细线建立层级。  
- **配色原则**：采用柔和、低饱和的统一配色，插图不能抢过标题和核心信息。  
- **最终检查**：重点检查文字大小一致性、错字漏项、信息完整性，以及缩小后是否仍清晰易读。

## 总结建议的skill参数

# 社区活动海报｜经验优化参数
# 用途：在生成社区类海报前读取，避免信息过满、插图琐碎、层级混乱等问题

poster_experience_rules:

  # 1. 整体风格
  visual_style:
    keywords:
      - 简约
      - 大气
      - 亲切
      - 轻松
      - 有呼吸感
    whitespace: "充足"
    information_density: "中低"
    color_saturation: "低至中"
    avoid:
      - 信息塞满画面
      - 传统宣传栏式排版
      - 大量装饰元素
      - 高饱和颜色堆叠
      - 过多卡片和色块

  # 2. 标题规则
  typography:
    main_title:
      priority: "最高"
      size: "大"
      color: "黑色优先"
      style: "简约但略有活泼感、亲和力"
      avoid:
        - 过度方正僵硬
        - 花哨艺术字
        - 复杂描边和阴影

    secondary_text:
      size: "明显小于主标题"
      style: "简洁易读"
      rule: "同一层级字号、字重保持统一"

    numeric_text:
      rule: "数字与对应中文单位视觉字号统一"
      example: "2026 与 年 不应出现明显大小差异"

  # 3. 文案精简
  content:
    principle: "核心信息优先，解释性文字能删则删"
    must_keep:
      - 活动名称
      - 时间
      - 地点
      - 核心活动内容
      - 参与方式
      - 必要提醒
    remove_first:
      - 重复解释
      - 无实际信息的小标语
      - 已能从标题理解的说明句
      - 为填满版面而增加的文字

  # 4. 插图规则
  illustration:
    style: "简约平涂矢量"
    strategy: "一个完整主场景优先"
    complexity: "低至中"
    people_density: "少量"
    object_density: "克制"

    simplify_priority:
      - 删除背景密集人头
      - 删除重复人物
      - 删除大量衣服和商品碎片
      - 删除无意义小物件
      - 删除零碎装饰

    preserve:
      - 主体人物
      - 核心场景
      - 必要摊位
      - 能表达活动性质的代表性物品

    rule: "保持主体造型和场景关系，优先做减法，而不是重新增加元素"

  # 5. 图标使用
  icons:
    default: "尽量不用"
    use_only_when: "能明显提升信息识别效率"
    avoid:
      - 每条信息配一个icon
      - 装饰性小图标
      - 重复表达文字含义的图标
      - 多套不同风格icon混用

  # 6. 信息模块
  layout:
    principle: "优先用留白建立层级，而不是依赖底色卡片"
    spacing: "偏宽松"
    bottom_information:
      style: "轻量、简洁"
      text_size: "小于主要活动信息"
      avoid:
        - 四个厚重卡片
        - 大面积浅色底框
        - 模块过度强调
        - 每个模块视觉权重相同

  # 7. 背景与容器
  containers:
    default_background: "干净浅色"
    text_background: "默认无底色"
    use_background_block_only_when: "确实需要区分重要信息"
    avoid:
      - 正文后方若有若无的浅色块
      - 大量圆角卡片
      - 为装饰而添加的容器

  # 8. 信息优先级
  hierarchy:
    level_1:
      - 主标题
    level_2:
      - 活动名称
      - 时间
      - 地点
    level_3:
      - 核心活动内容
      - 参与方式
    level_4:
      - 交易提醒
      - 天气说明
      - 补充规则

  # 9. 生成前自检
  pre_generation_check:
    - "是否可以再删掉20%左右的非必要元素？"
    - "是否只有一个主要视觉中心？"
    - "主标题是否第一眼可见？"
    - "插图是否出现过多人头、衣物或商品碎片？"
    - "是否使用了过多icon、卡片或浅色底框？"
    - "信息之间是否留有足够空间？"

  # 10. 生成后自检
  post_generation_check:
    - "检查同层级文字字号是否一致"
    - "检查数字与中文单位大小是否协调"
    - "检查错字、漏字和日期"
    - "检查时间、地点、参与方式是否容易找到"
    - "检查缩小后正文是否仍可读"
    - "检查插图是否抢夺标题视觉焦点"
    - "若画面仍显拥挤，优先删元素，不优先缩小所有文字"

  # 11. 核心经验
  learned_principle:
    - "社区海报不是元素越丰富越好，而是信息越容易被看到越好。"
    - "出现杂乱时优先做减法：减人物、减图标、减卡片、减解释文字。"
    - "留白本身就是版式元素，不需要把每一块空间填满。"
    - "主插图负责营造氛围，文字负责传递信息，两者不要争夺视觉中心。"
