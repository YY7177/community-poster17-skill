# 完整海报prompt规范

## 一致结构，可变设计

所有主题与风格沿用九段，按顺序输出。固定的是信息槽位，**不是图案、三卡片位置或具体构图**。由Codex读本次资料后填写，脚本只组装，不调用文本模型。

写九段前必须先在内部完成四步转换，不把用户原文直接换行塞入模板：

1. **事实锁定**：逐项建立两语facts，标出不可改的日期、地点、对象、项目、条件、步骤、电话与必要警示。
2. **信息层级**：确定主视觉标题、第一眼信息、第二层行动信息和底部长说明。一般第一眼只承载最需要居民立即理解的2—4项，不把所有文字做成同级。
3. **风格语法**：从所选参考图提取媒介、边缘、体积/纹理、色彩关系与标题气质，再从活动内容选择2—5个真正相关的场景元素或抽象母题；二者结合形成视觉语言。
4. **图文构图**：规定标题怎样进入场景、主题元素怎样引导视线、关键信息由什么形状/数字/符号承载、长文本怎样保持可读。至少描述一条从标题到关键信息再到底部说明的阅读动线。

每次prompt都要具体回答“画什么、放在哪里、用什么媒介、与哪段文字怎样连接、先看什么后看什么”。只写“高级、好看、活泼、视觉冲击”不合格；只给网格式坐标或把所有内容装进相同卡片也不合格。

1. **规格与视觉风格**：语言、竖版比例、目标尺寸、媒介、配色、展示气质。
2. **参考图与场景依据**：图1为本次Nano Banana风格场景结果；原社区图若附上作为图2。说明保留的可见关系与可裁切范围；参考图内旧字不能沿用。
3. **艺术标题与字形**：艺术主标题、通知副标题、对应字形材质、字号对比与叠压关系。标题可跨建筑、树冠或插画，不强制变成居中大标题。
4. **主题元素与视觉动线**：把本次活动/服务转成可见图形，交代位置、数量关系、媒介和连接方式；避免只写“漂亮高级”。
5. **关键信息组合**：日期、地点、对象/行动如何成为视觉组合。写明大数字、标签、承托形状、符号与相互关系。日期可拆成年/月/日形成字号对比，地点可与路径、门牌或空间轮廓结合，对象可与人物/身份符号结合，步骤可成为连续动线；按内容采用合组、路径、带状、局部色块等，不只普通列表，不机械每项一张卡。
6. **内容与行动呈现**：活动项目、服务内容或执行步骤的准确文案与载体；装饰不能替代项目名称。
7. **提示、条件与落款**：长提示/限制/来源与邀请语的文字和承托方式，缺少机构/电话时不新增。
8. **整体成图要求**：图文共同设计、独立海报非环境mockup、可读层级、主题配色克制、无假Logo/二维码。要求模型尽力准确呈现文字，但不承诺其会做到。
9. **上图文字清单**：脚本逐项列出该语facts，要求全部进入同一张海报，字段ID只在prompt中不印到图上。英文清单与中文同事实，布局可适配语长。

同一事实可以在设计指令与清单重复出现，不表示要求成图重复印字。设计指令不得与文字清单冲突。缺少某类内容时保留该段，说明不额外添加该类事实。

## 风格与元素相配

| 媒介示例 | 同主题元素的表现与信息设计 |
| --- | --- |
| 彩纸剪贴 | 游戏/纸花变为有纸纤维和叠层的剪纸；日期是裁切大数字，地点可沿弧形纸带；连接纸屑与弧线 |
| 软萌黏土或立体造型 | 亲子、宠物、手工或服务动作转成圆润微缩场景；日期是压印/捏塑数字，地点可用柔软丝带或立体路牌，连接蜿蜒材质线；不照搬纸纹 |
| 蜡笔、水彩或彩铅手绘 | 人物与材料用手绘线、颗粒和晕染；日期采用笔触字，地点沿手绘路径；正文承托面保持干净对比 |
| 简洁几何矢量 | 人物、器材和动作简化为几何符号；日期与路径节点组合，地点用导向带；通过尺度和留白建立层级，避免强加黏土阴影 |
| 复古丝网或版画 | 按主题选符号，使用有限专色、套印和粗颗粒；标题为印刷展示字；必要通知不做过度破损 |
| 摄影与字形拼贴 | 保留摄影关系，标题作为跨画面的字形形体；主题元素用切片、透明色带、贴纸或局部遮罩，避免盖住关键事实 |
| 编辑设计与抽象图形 | 用圆、弧线、箭头、编号、印章、几何切片建立节奏；让信息本身成为构图，不默认使用照片卡片或规则宫格 |
| 儿童绘本或扁平插画 | 用圆润人物、动作场景与道具串联活动步骤；信息载体可沿故事路径变化，避免把儿童主题等同于固定彩虹、云朵和三张卡片 |

## 内容与视觉母题相配

| 内容类型 | 优先转换成的视觉信息；只能使用用户资料支持的事实 |
| --- | --- |
| 儿童/亲子活动 | 游戏、手工、阅读、互动动作；日期可成为节奏核心，地点与人物路径连接；长提醒放在安静底栏 |
| 消防/疏散/安全 | 集合点、方向、行动顺序、听从指挥等已给信息；用清晰箭头、编号和高对比警示层级，不补造消防器材或演练细节 |
| 志愿招募/岗位 | 岗位类型、资格、时段、报名流程；可用协作人物、岗位符号、流程节点，不能省略限制和确认方式 |
| 便民服务/健康 | 服务项目、适用对象、时间地点、注意事项；用服务路径或动作组合，避免无依据的医疗图示和疗效承诺 |
| 宠物友好/文明倡议 | 牵引、清洁、避让、入场条件、协调渠道；用人与宠物关系、路径和规则符号串联，不让可爱插画削弱限制 |
| 普法/公共通知 | 核心权利义务、办理或咨询路径、时间地点；用资料、对话、印章、编号与导向关系，避免假法规编号和官方标志 |

同一种内容在不同媒介中必须换成该媒介的原生表达；同一种媒介面对不同内容也必须更换主题元素和信息结构。可以有大标题、图文叠压、错落纸片或路径式布局，但这些都是按任务选择的设计结果，不是默认组件。

以上只是可选媒介，不固定每次提供其中哪三种。六主题按实际事实转换：消防用真实活动里的器材/疏散动线，便民用服务步骤或地点导向，出行用路径，普法用资料/对话隐喻，志愿用协作关系，健康用已给出的行动提示；不凭主题补造器材、服务点、药物或法规。

## 中间风格图prompt

将所选媒介、配色、照片可见关系和主题元素组织为一张风格场景图，**不写最终标题、日期或正文**。不要求固定留白、不预制三卡片、不制作完整海报概念稿。图1约束场景，图2约束媒介。该图仅供豆包接力，最终图文和版式由完整海报prompt决定。

## 文件与工具

`prompt-plan.json` 包含任务ID、canvas（默认1200×1500）、languages（默认zh/en）、style（name/medium/palette）、`visual_scene`、`visual_elements`、facts和两语的七个设计段。每个fact包含id/zh/en；`poster_sections.zh`和`.en`分别包含 `reference`、`title`、`elements`、`information`、`content`、`footer`、`finish` 七个非空文本字段。英文prompt可以用中文描述设计，但清单与要求生成的海报语言为英文，地点等专名可保留。九段标题和顺序始终一致；段内设计必须针对本次内容重新写，不能从旧任务复制后只替换日期地点。

运行 `scripts/build_prompts.py` 保存 `nano-banana-prompts.json`（只有一条的插件批量输入）、`nano-banana-prompt.txt`、`poster-prompt-zh.txt`、`poster-prompt-en.txt`、`prompt-manifest.json`。不加入密钥，不让用户额外确认prompt。示例见[儿童剪纸方案](examples/children-paper-plan.json)；例子的日期地点不能进入其他任务。
